# رايدو كار — RIDO CAR

موقع تعريفي عربي RTL مستقل، دون تعديل مشاريع Flutter أو Supabase. ملفات النشر فقط في `site/`؛ لا توجد قاعدة بيانات أو نماذج لجمع البيانات أو تحليلات أو خدمات مدفوعة أو اعتماديات بناء.

## معاينة محلية

من `C:\src\rido-car-website` شغّل `node tools/preview.mjs` ثم افتح `http://127.0.0.1:8787`.

## النشر المجاني على GitHub Pages

1. عند عدم وجود صلاحية محفوظة، شغّل `git credential-manager github login` وأكمل تسجيل الدخول بنفسك في المتصفح. لا ترسل token أو كلمة مرور في المحادثة.
2. شغّل `node tools/publish.mjs` من هذا المجلد. يستخدم Git Credential Manager في الذاكرة دون كتابة token في الملفات أو الرابط أو المخرجات. ينشئ مستودعًا عامًا جديدًا للموقع فقط، ولا يستبدل مستودعًا موجودًا. يرفع الملفات المحددة فقط، ويفعّل Pages وHTTPS وWorkflow الرسمي.
3. انتظر نجاح Workflow في Actions، ثم تحقق من الصفحة الرئيسية و`privacy.html` عبر HTTPS قبل استخدام الرابطين في Meta. الرابط الذي يطبعه مساعد النشر قبل اكتمال Actions هو وجهة النشر المطلوبة، وليس إثباتًا على إتاحة الموقع بعد.

ملف `.publish-state.json` محلي مستثنى من Git يتيح متابعة محاولة النشر نفسها عند انقطاعها. لا تضف إليه أسرارًا. ملف Actions يرفع مجلد `site` وحده، مع إجراءات GitHub الرسمية المثبتة ببصمات commits والتحقق من إصداراتها في 8 نوفمبر 2026.

إذا كان الحساب لا يملك الصلاحيات المطلوبة، يبقى الموقع جاهزًا محليًا دون ادعاء وجود رابط عام. يمكن كذلك رفع محتويات `site` إلى مستودع عام يدويًا وتفعيل Settings → Pages → Deploy from a branch → main / root؛ أو رفع المشروع كاملًا واختيار مصدر GitHub Actions لملف workflow المرفق.

## المحتوى والخصوصية

- استُخدم شعار الراكب المعتمد بنسخة مستقلة؛ لم يُعدّل الأصل.
- تعريف الخدمة يقتصر على الرحلات والربط بين الركاب والكباتن في الأردن. التطبيق موصوف بصدق بأنه في التطوير والتجربة؛ لا أسعار أو وعود توفر أو تنزيلات غير موجودة أو شهادات عملاء وهمية.
- الدعم الحقيقي: https://wa.me/962782630529. لا حجز أو دفع عبر هذا الموقع.
- الخصوصية تستند إلى وظائف الكود الحالي: الحساب والموقع والرحلات والتقييمات والمحفظة والإحالات؛ وتوضح أن OTP وبعض Push غير مفعّلين بالكامل. لم تُخترع مدة حذف أو إقامة بيانات داخل الأردن أو شهادة تدقيق أمني. طلبات الوصول والتصحيح والحذف عبر الدعم تُراجع بعد التحقق من ملكية الحساب، ولا يُفترض اكتمال الحذف بمجرد إرسال الطلب.
- الموقع لا يضيف cookies أو أدوات تتبع. GitHub قد يسجل IP الزوار لأغراض الأمان؛ أوضحنا ذلك وضمّنا روابط سياسات المزودين.
- هذه الصفحة لا تثبت اعتماد Meta أو ملكية قانونية أو ترخيص تشغيل، ولا تغني عن استكمال المتطلبات التنظيمية والعقود الفعلية عند الإطلاق. يجب تحديث سياسة الخصوصية عند تغير الممارسات الفعلية، خاصة تفعيل WhatsApp OTP والإشعارات والاحتفاظ بالبيانات.
